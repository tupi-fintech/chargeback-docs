# API Data – Agent AI – Chargeback

## Data Privacy & Compliance

No raw card number (PAN), CVV, or other card authentication data is ever sent to the AI recommendation engine — only the card network (`card_brand`) and masked/aggregate transaction data (amounts, dates, and internal identifiers) are used. Free-text fields (`cardholder_claim`, `merchant_response`) may contain personal data provided by the dispute parties and are processed solely for chargeback recommendation and evidence-analysis purposes. Evidence files are processed only for OCR and document classification; no cardholder authentication data (track data, PIN, CVV) is ever extracted or stored. This processing is carried out in accordance with LGPD (Lei 13.709/2018), GDPR, and PCI-DSS data minimization and scope-limitation principles.

Input

```jsonc
{
  "organization_id": "org_12133232",
  "contract_dispute_id": "cd_1234567890",
  "cycle_id": "cy_1223232",
  "language": "en",
  "reason_code": "13.1 - Merchandise/Services Not Received",
  "card_brand": "visa", // enum: visa | master | elo | amex
  "transaction": {
    "authorized_at": "2025-01-15T14:30:00Z",
    "merchant_id": "MERCH-12345",
    "currency": "USD",
    "amount": 29999
  },
  "chargeback": {
    "received_at": "2025-02-20T09:15:00Z",
    "cycle_type": null,
    "amount": 29999
  },
  "details": {
    "cardholder_claim": "Customer claims package was never delivered despite tracking showing delivery confirmation",
    "merchant_response": "Merchant refutes claim"
  }
}
```

### Recommendation Request Fields

| **Field**                  | **Type**           | **Required** | **Description**                                                      | **Example**                                  |
| --------------------------- | ------------------ | ------------- | ---------------------------------------------------------------------- | ----------------------------------------------- |
| `organization_id`           | String              | Yes           | Tupi's internal organization identifier                                | `"org_12133232"`                                 |
| `contract_dispute_id`       | String              | Yes           | Tupi's internal unique identifier for the dispute contract             | `"cd_1234567890"`                                 |
| `cycle_id`                  | String              | Yes           | Tupi's internal identifier for the dispute cycle                       | `"cy_1223232"`                                    |
| `language`                  | String (ISO 639-1) | Yes           | Language code used for texts                                           | `"en"`                                            |
| `reason_code`                | String              | Yes           | Chargeback reason code and description according to the card network  | `"13.1 - Merchandise/Services Not Received"`      |
| `card_brand`                 | String (enum)       | Yes           | Card network/brand involved in the transaction. Values: `visa`, `master`, `elo`, `amex` | `"visa"`                       |
| `transaction`                | Object               | No            | Original transaction details                                            | *See subfields below*                             |
| `transaction.authorized_at`  | String (RFC 3339)   | No            | Original transaction authorization date and time (UTC)                  | `"2025-01-15T14:30:00Z"`                          |
| `transaction.merchant_id`    | String               | No            | Unique merchant identifier                                              | `"MERCH-12345"`                                   |
| `transaction.currency`       | String               | No            | Transaction currency code                                                | `"USD"`                                           |
| `transaction.amount`         | Decimal              | Yes           | Transaction amount in the smallest currency unit                        | `29999` (=$299.99)                                |
| `chargeback`                  | Object               | Yes           | Specific dispute details                                                | *See subfields below*                             |
| `chargeback.received_at`      | String (RFC 3339)    | Yes           | Date and time the chargeback was received (UTC)                         | `"2025-02-20T09:15:00Z"`                          |
| `chargeback.cycle_type`       | String                | No            | Dispute cycle type, when applicable                                     | `null`                                            |
| `chargeback.amount`           | Decimal               | Yes           | Chargeback amount in the smallest currency unit                         | `29999`                                           |
| `details`                      | Object                | No            | Additional dispute information                                          | *See subfields below*                             |
| `details.cardholder_claim`     | String                | No            | Description of the claim made by the cardholder                        | `"Customer claims package was never delivered..."`|
| `details.merchant_response`    | String                | No            | Description of the response made by the merchant                       | `"Merchant refutes claim"`                        |

## Evidence Upload

Evidence files (e.g. proof of delivery, invoices, communication logs) are sent as a separate `multipart/form-data` request, linked to the same dispute through the identifiers below. Each file is processed independently for OCR and document classification, and the result is associated with the dispute.

### Evidence Upload Request Fields

| **Field**             | **Type**  | **Required** | **Description**                                                    | **Example**          |
| ----------------------- | --------- | ------------- | ---------------------------------------------------------------------- | ----------------------- |
| `file`                   | Binary    | Yes           | Evidence file content                                                  | *binary file*           |
| `organization_id`        | String    | Yes           | Tupi's internal organization identifier                                | `"org_12133232"`        |
| `contract_dispute_id`    | String    | Yes           | Tupi's internal unique identifier for the dispute contract             | `"cd_1234567890"`       |
| `cycle_id`               | String    | Yes           | Tupi's internal identifier for the dispute cycle                       | `"cy_1223232"`          |
| `step_id`                | String    | Yes           | Identifier of the dispute step this evidence belongs to                | `"step_123456"`         |
| `step_type`              | String    | Yes           | Type of the dispute step                                               | `"chargeback"`          |
| `reason_code`             | String    | No            | Chargeback reason code, when applicable                                | `"10.1"`                |
| `filename`                | String    | Yes           | Original file name                                                     | `"evidence.pdf"`        |
