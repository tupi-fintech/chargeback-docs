# API Data – Agent AI – Chargeback

## Data Privacy & Compliance

No raw card number (PAN), CVV, or other card authentication data is ever sent to the AI recommendation engine — only the card network (`card_brand`) and masked/aggregate transaction data (amounts, dates, and internal identifiers) are used. Free-text fields (`cardholder_claim`, `merchant_response`) may contain personal data provided by the dispute parties and are processed solely for chargeback recommendation and evidence-analysis purposes. Evidence files are processed only for OCR and document classification; no cardholder authentication data (track data, PIN, CVV) is ever extracted or stored. This processing is carried out in accordance with LGPD (Lei 13.709/2018), GDPR, and PCI-DSS data minimization and scope-limitation principles.

## Evidence Upload

Evidence files (e.g. proof of delivery, invoices, communication logs) are sent as a separate `multipart/form-data` request, linked to the same dispute through the identifiers below. Each file is processed independently for OCR and document classification, and the result is associated with the dispute.

### Evidence Upload Request Fields

| **Field**             | **Type**  | **Required** | **Description**                                                    | **Example**          |
| ----------------------- | --------- | ------------- | ---------------------------------------------------------------------- | ----------------------- |
| `file`                   | Binary    | Yes           | Evidence file content                                                  | *binary file*           |
| `organization_id`        | String    | Yes           | Tupi's internal organization identifier                                | `"org_12133232"`        |
| `contract_dispute_id`    | String    | Yes           | Tupi's internal unique identifier for the dispute contract             | `"cd_1234567890"`       |
| `cycle_id`               | String    | Yes           | Tupi's internal identifier for the dispute cycle                       | `"cy_1223232"`          |
| `step_id`                | String    | Yes           | Identifier of the dispute step this evidence belongs to                | `"step_123456"`         |
| `step_type`              | String    | Yes           | Type of the dispute step                                               | `"chargeback"`          |
| `reason_code`             | String    | No            | Chargeback reason code, when applicable                                | `"10.1"`                |
| `filename`                | String    | Yes           | Original file name                                                     | `"evidence.pdf"`        |

### AI Analysis Result

After the evidence file is processed by the AI/OCR pipeline, the following data is extracted and persisted. This record is used in the downstream recommendation flow and documents what data points are derived from partner-submitted evidence.

```jsonc
{
  "status": "success",
  "request_id": "req_abc123",
  "document": {
    "filename": "evidence.pdf",
    "category": "proof_of_delivery"
  },
  "extracted_data": {
    "raw_text": "Delivered on 2025-01-15 at 14:30, signed by J. Silva",
    "analysis": {
      "document_intent": "Confirms delivery of goods to cardholder address",
      "missing_info": "No signature image included",
      "confidence_summary": "High confidence — delivery date and recipient name present"
    }
  },
  "metadata": {
    "processing_time_ms": 1240,
    "llm_model": "...",   // vendor not disclosed
    "ocr_method": "...",  // vendor not disclosed
    "token_usage": {
      "prompt_tokens": 512,
      "response_tokens": 128,
      "total_tokens": 640
    }
  }
}
```

| **Field**                               | **Type**  | **Description**                                                                   |
| ----------------------------------------- | --------- | ------------------------------------------------------------------------------------ |
| `status`                                  | String    | Processing status                                                                    |
| `request_id`                              | String    | Unique identifier for this analysis request                                          |
| `document`                                | Object    | Information about the analyzed document                                              |
| `document.filename`                       | String    | Original file name                                                                   |
| `document.category`                       | String    | Document category identified by the AI (e.g. `proof_of_delivery`, `invoice`)        |
| `extracted_data`                          | Object    | Data extracted from the document                                                     |
| `extracted_data.raw_text`                 | String    | Full text extracted from the document via OCR                                        |
| `extracted_data.analysis`                 | Object    | AI interpretation of the document content                                            |
| `extracted_data.analysis.document_intent` | String    | Summary of what the document demonstrates in the context of the dispute              |
| `extracted_data.analysis.missing_info`    | String    | Information expected but absent in the document                                      |
| `extracted_data.analysis.confidence_summary` | String | Human-readable confidence assessment of the extracted data                           |
| `metadata`                                | Object    | Processing metadata                                                                  |
| `metadata.processing_time_ms`             | Integer   | Time taken to process the document, in milliseconds                                  |
| `metadata.llm_model`                      | String    | AI model used (vendor not disclosed)                                                 |
| `metadata.ocr_method`                     | String    | OCR method used (vendor not disclosed)                                               |
| `metadata.token_usage`                    | Object    | Token consumption for the AI analysis                                                |
| `metadata.token_usage.prompt_tokens`      | Integer   | Tokens used in the prompt                                                            |
| `metadata.token_usage.response_tokens`    | Integer   | Tokens used in the response                                                          |
| `metadata.token_usage.total_tokens`       | Integer   | Total tokens consumed                                                                |

## AI Recommendation Engine

### Request

Input

```jsonc
{
  "organization_id": "org_12133232",
  "contract_dispute_id": "cd_1234567890",
  "cycle_id": "cy_1223232",
  "language": "en",
  "reason_code": "13.1 - Merchandise/Services Not Received",
  "card_brand": "visa", 
  "transaction": {
    "authorized_at": "2025-01-15T14:30:00Z",
    "merchant_id": "MERCH-12345",
    "currency": "USD",
    "amount": 29999
  },
  "chargeback": {
    "received_at": "2025-02-20T09:15:00Z",
    "cycle_type": null,
    "amount": 29999
  },
  "details": {
    "cardholder_claim": "Customer claims package was never delivered despite tracking showing delivery confirmation",
    "merchant_response": "Merchant refutes claim"
  }
}
```

#### Recommendation Request Fields

| **Field**                  | **Type**           | **Required** | **Description**                                                      | **Example**                                  |
| --------------------------- | ------------------ | ------------- | ---------------------------------------------------------------------- | ----------------------------------------------- |
| `organization_id`           | String              | Yes           | Tupi's internal organization identifier                                | `"org_12133232"`                                 |
| `contract_dispute_id`       | String              | Yes           | Tupi's internal unique identifier for the dispute contract             | `"cd_1234567890"`                                 |
| `cycle_id`                  | String              | Yes           | Tupi's internal identifier for the dispute cycle                       | `"cy_1223232"`                                    |
| `language`                  | String (ISO 639-1) | Yes           | Language code used for texts                                           | `"en"`                                            |
| `reason_code`                | String              | Yes           | Chargeback reason code and description according to the card network  | `"13.1 - Merchandise/Services Not Received"`      |
| `card_brand`                 | String (enum)       | Yes           | Card network/brand involved in the transaction. Values: `visa`, `master`, `elo`, `amex` | `"visa"`                       |
| `transaction`                | Object               | No            | Original transaction details                                            | *See subfields below*                             |
| `transaction.authorized_at`  | String (RFC 3339)   | No            | Original transaction authorization date and time (UTC)                  | `"2025-01-15T14:30:00Z"`                          |
| `transaction.merchant_id`    | String               | No            | Unique merchant identifier                                              | `"MERCH-12345"`                                   |
| `transaction.currency`       | String               | No            | Transaction currency code                                                | `"USD"`                                           |
| `transaction.amount`         | Decimal              | Yes           | Transaction amount in the smallest currency unit                        | `29999` (=$299.99)                                |
| `chargeback`                  | Object               | Yes           | Specific dispute details                                                | *See subfields below*                             |
| `chargeback.received_at`      | String (RFC 3339)    | Yes           | Date and time the chargeback was received (UTC)                         | `"2025-02-20T09:15:00Z"`                          |
| `chargeback.cycle_type`       | String                | No            | Dispute cycle type, when applicable                                     | `null`                                            |
| `chargeback.amount`           | Decimal               | Yes           | Chargeback amount in the smallest currency unit                         | `29999`                                           |
| `details`                      | Object                | No            | Additional dispute information                                          | *See subfields below*                             |
| `details.cardholder_claim`     | String                | No            | Description of the claim made by the cardholder                        | `"Customer claims package was never delivered..."`|
| `details.merchant_response`    | String                | No            | Description of the response made by the merchant                       | `"Merchant refutes claim"`                        |

### Response

```jsonc
{
  "status": "processed",
  "analysis": {
    "primary_defense_scenario": "Proof of delivery available",
    "evidence_quality": "strong",
    "evidence_symbol": "✅",
    "key_strengths": ["Signed delivery confirmation", "Tracking log matches merchant records"],
    "key_weaknesses": ["No customer communication log"],
    "win_probability": {
      "confidence_level": "high",
      "range": "75-90%",
      "percentage": 82
    },
    "document_analysis": {
      "critical_documents_present": ["delivery_confirmation.pdf"],
      "missing_critical_documents": [],
      "document_quality_issues": [],
      "total_documents_reviewed": 1
    }
  },
  "recommendation": {
    "decision": "dispute",
    "rationale": "Evidence strongly supports merchant's position",
    "next_steps": ["Submit delivery confirmation as primary evidence", "Include tracking log"]
  }
}
```

#### Recommendation Response Fields

| **Field**                                        | **Type**        | **Description**                                                              |
| -------------------------------------------------- | --------------- | ------------------------------------------------------------------------------- |
| `status`                                           | String          | Processing status of the recommendation                                         |
| `analysis`                                         | Object          | AI analysis of the dispute and evidence                                         |
| `analysis.primary_defense_scenario`                | String          | The main defense strategy identified for the dispute                            |
| `analysis.evidence_quality`                        | String          | Overall quality assessment of the evidence provided                             |
| `analysis.evidence_symbol`                         | String          | Visual indicator of evidence quality                                            |
| `analysis.key_strengths`                           | Array\<String\> | List of factors that support the merchant's position                            |
| `analysis.key_weaknesses`                          | Array\<String\> | List of gaps or weaknesses in the current evidence                              |
| `analysis.win_probability`                         | Object          | Estimated probability of winning the dispute                                    |
| `analysis.win_probability.confidence_level`        | String          | Confidence level of the probability estimate (e.g. `high`, `medium`, `low`)    |
| `analysis.win_probability.range`                   | String          | Probability range expressed as a percentage interval                            |
| `analysis.win_probability.percentage`              | Integer         | Central probability estimate as a percentage                                    |
| `analysis.document_analysis`                       | Object          | Assessment of the documents submitted                                           |
| `analysis.document_analysis.critical_documents_present`  | Array\<String\> | Documents present that are critical for the dispute                       |
| `analysis.document_analysis.missing_critical_documents`  | Array\<String\> | Critical documents that are absent                                        |
| `analysis.document_analysis.document_quality_issues`     | Array\<String\> | Quality issues identified in submitted documents                          |
| `analysis.document_analysis.total_documents_reviewed`    | Integer         | Total number of documents reviewed                                        |
| `recommendation`                                   | Object          | Final recommendation                                                            |
| `recommendation.decision`                          | String          | Recommended action (e.g. `dispute`, `accept`)                                  |
| `recommendation.rationale`                         | String          | Explanation of the recommendation                                               |
| `recommendation.next_steps`                        | Array\<String\> | Ordered list of actions to take                                                 |
