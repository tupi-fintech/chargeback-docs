# Dados da API – IA Agente – Chargeback

## Privacidade de Dados e Compliance

Nenhum número de cartão (PAN), CVV ou outro dado de autenticação do cartão é enviado ao motor de recomendação por IA — apenas a bandeira do cartão (`card_brand`) e dados agregados/mascarados da transação (valores, datas e identificadores internos) são utilizados. Campos de texto livre (`cardholder_claim`, `merchant_response`) podem conter dados pessoais fornecidos pelas partes da disputa e são processados exclusivamente para fins de recomendação de chargeback e análise de evidências. Arquivos de evidência são processados apenas para OCR e classificação de documento; nenhum dado de autenticação do portador do cartão (dados da tarja, PIN, CVV) é extraído ou armazenado. Esse processamento é realizado em conformidade com a LGPD (Lei 13.709/2018), o GDPR e os princípios de minimização de dados e limitação de escopo do PCI-DSS.

## Envio de Evidências

Arquivos de evidência (ex.: comprovante de entrega, notas fiscais, registros de comunicação) são enviados em uma requisição separada, no formato `multipart/form-data`, vinculados à mesma disputa por meio dos identificadores abaixo. Cada arquivo é processado individualmente para OCR e classificação de documento, e o resultado é associado à disputa.

### Campos da Requisição de Envio de Evidência

| **Campo**             | **Tipo**  | **Obrigatório** | **Descrição**                                                     | **Exemplo**           |
| ----------------------- | --------- | ----------------- | ----------------------------------------------------------------------- | ------------------------ |
| `file`                   | Binário   | Sim                | Conteúdo do arquivo de evidência                                       | *arquivo binário*         |
| `organization_id`        | String    | Sim                | Identificador interno da organização na Tupi                            | `"org_12133232"`          |
| `contract_dispute_id`    | String    | Sim                | Identificador interno único do contrato de disputa na Tupi              | `"cd_1234567890"`         |
| `cycle_id`               | String    | Sim                | Identificador interno do ciclo de disputa na Tupi                       | `"cy_1223232"`            |
| `step_id`                | String    | Sim                | Identificador da etapa da disputa à qual a evidência pertence           | `"step_123456"`           |
| `step_type`              | String    | Sim                | Tipo da etapa da disputa                                                | `"chargeback"`            |
| `reason_code`             | String    | Não                | Código de motivo do chargeback, quando aplicável                       | `"10.1"`                  |
| `filename`                | String    | Sim                | Nome original do arquivo                                                | `"evidence.pdf"`          |

### Resultado da Análise por IA

Após o processamento do arquivo pelo pipeline de IA/OCR, os seguintes dados são extraídos e persistidos. Esse registro é utilizado no fluxo de recomendação e documenta os dados derivados das evidências enviadas pelo parceiro.

```jsonc
{
  "status": "success",
  "request_id": "req_abc123",
  "document": {
    "filename": "evidence.pdf",
    "category": "proof_of_delivery"
  },
  "extracted_data": {
    "raw_text": "Entregue em 15/01/2025 às 14:30, assinado por J. Silva",
    "analysis": {
      "document_intent": "Confirma a entrega dos produtos no endereço do portador do cartão",
      "missing_info": "Imagem da assinatura não incluída",
      "confidence_summary": "Alta confiança — data de entrega e nome do destinatário presentes"
    }
  },
  "metadata": {
    "processing_time_ms": 1240,
    "llm_model": "...",   
    "ocr_method": "...",  
    "token_usage": {
      "prompt_tokens": 512,
      "response_tokens": 128,
      "total_tokens": 640
    }
  }
}
```

| **Campo**                                     | **Tipo**  | **Descrição**                                                                        |
| ----------------------------------------------- | --------- | --------------------------------------------------------------------------------------- |
| `status`                                        | String    | Status do processamento                                                                  |
| `request_id`                                    | String    | Identificador único da requisição de análise                                             |
| `document`                                      | Object    | Informações sobre o documento analisado                                                  |
| `document.filename`                             | String    | Nome original do arquivo                                                                 |
| `document.category`                             | String    | Categoria do documento identificada pela IA (ex.: `proof_of_delivery`, `invoice`)       |
| `extracted_data`                                | Object    | Dados extraídos do documento                                                             |
| `extracted_data.raw_text`                       | String    | Texto completo extraído do documento via OCR                                             |
| `extracted_data.analysis`                       | Object    | Interpretação do conteúdo do documento pela IA                                           |
| `extracted_data.analysis.document_intent`       | String    | Resumo do que o documento demonstra no contexto da disputa                               |
| `extracted_data.analysis.missing_info`          | String    | Informações esperadas mas ausentes no documento                                          |
| `extracted_data.analysis.confidence_summary`    | String    | Avaliação legível da confiança nos dados extraídos                                       |
| `metadata`                                      | Object    | Metadados do processamento                                                               |
| `metadata.processing_time_ms`                   | Integer   | Tempo de processamento do documento, em milissegundos                                    |
| `metadata.llm_model`                            | String    | Modelo de IA utilizado (fornecedor não divulgado)                                        |
| `metadata.ocr_method`                           | String    | Método de OCR utilizado (fornecedor não divulgado)                                       |
| `metadata.token_usage`                          | Object    | Consumo de tokens da análise por IA                                                      |
| `metadata.token_usage.prompt_tokens`            | Integer   | Tokens utilizados no prompt                                                              |
| `metadata.token_usage.response_tokens`          | Integer   | Tokens utilizados na resposta                                                            |
| `metadata.token_usage.total_tokens`             | Integer   | Total de tokens consumidos                                                               |

## Motor de Recomendação por IA

![Recomendação de IA](../images/ai-recommendation.png)

### Requisição

Entrada

```jsonc
{
  "organization_id": "org_12133232",
  "contract_dispute_id": "cd_1234567890",
  "cycle_id": "cy_1223232",
  "language": "pt-BR",
  "reason_code": "13.1 - Merchandise/Services Not Received",
  "card_brand": "visa", 
  "transaction": {
    "authorized_at": "2025-01-15T14:30:00Z",
    "merchant_id": "MERCH-12345",
    "currency": "BRL",
    "amount": 29999
  },
  "chargeback": {
    "received_at": "2025-02-20T09:15:00Z",
    "cycle_type": null,
    "amount": 29999
  },
  "details": {
    "cardholder_claim": "Cliente alega que o pacote nunca foi entregue, apesar do rastreamento mostrar confirmação de entrega",
    "merchant_response": "Comerciante refuta a alegação"
  }
}
```

#### Campos da Requisição de Recomendação

| **Campo**                  | **Tipo**            | **Obrigatório** | **Descrição**                                                          | **Exemplo**                                       |
| --------------------------- | -------------------- | ----------------- | -------------------------------------------------------------------------- | ---------------------------------------------------- |
| `organization_id`           | String                | Sim                | Identificador interno da organização na Tupi                               | `"org_12133232"`                                      |
| `contract_dispute_id`       | String                | Sim                | Identificador interno único do contrato de disputa na Tupi                 | `"cd_1234567890"`                                     |
| `cycle_id`                  | String                | Sim                | Identificador interno do ciclo de disputa na Tupi                          | `"cy_1223232"`                                        |
| `language`                  | String (ISO 639-1)   | Sim                | Código do idioma usado para textos                                         | `"pt-BR"`                                             |
| `reason_code`                | String                | Sim                | Código de motivo e descrição do chargeback conforme a rede                | `"13.1 - Merchandise/Services Not Received"`          |
| `card_brand`                 | String (enum)         | Sim                | Rede/bandeira do cartão envolvida na transação. Valores: `visa`, `master`, `elo`, `amex` | `"visa"`                          |
| `transaction`                | Object                 | Não                | Detalhes da transação original                                              | *Veja subcampos abaixo*                               |
| `transaction.authorized_at`  | String (RFC 3339)     | Não                | Data e hora de autorização da transação original (UTC)                     | `"2025-01-15T14:30:00Z"`                              |
| `transaction.merchant_id`    | String                 | Não                | Identificador único do comerciante                                          | `"MERCH-12345"`                                       |
| `transaction.currency`       | String                 | Não                | Código da moeda da transação                                                | `"BRL"`                                               |
| `transaction.amount`         | Decimal                | Sim                | Valor da transação na menor unidade monetária                              | `29999` (=R$299,99)                                   |
| `chargeback`                  | Object                 | Sim                | Detalhes específicos da disputa                                             | *Veja subcampos abaixo*                               |
| `chargeback.received_at`      | String (RFC 3339)      | Sim                | Data e hora em que o chargeback foi recebido (UTC)                         | `"2025-02-20T09:15:00Z"`                              |
| `chargeback.cycle_type`       | String                  | Não                | Tipo do ciclo de disputa, quando aplicável                                  | `null`                                                |
| `chargeback.amount`           | Decimal                 | Sim                | Valor do chargeback na menor unidade monetária                             | `29999`                                               |
| `details`                      | Object                  | Não                | Informações adicionais da disputa                                           | *Veja subcampos abaixo*                               |
| `details.cardholder_claim`     | String                  | Não                | Descrição da alegação feita pelo portador do cartão                        | `"Cliente alega que o pacote nunca foi entregue..."`  |
| `details.merchant_response`    | String                  | Não                | Descrição da resposta fornecida pelo comerciante                           | `"Comerciante refuta a alegação"`                     |

### Resposta

```jsonc
{
  "status": "processed",
  "analysis": {
    "primary_defense_scenario": "Comprovante de entrega disponível",
    "evidence_quality": "strong",
    "evidence_symbol": "✅",
    "key_strengths": ["Confirmação de entrega assinada", "Log de rastreamento coincide com os registros do comerciante"],
    "key_weaknesses": ["Sem registro de comunicação com o cliente"],
    "win_probability": {
      "confidence_level": "high",
      "range": "75-90%",
      "percentage": 82
    },
    "document_analysis": {
      "critical_documents_present": ["delivery_confirmation.pdf"],
      "missing_critical_documents": [],
      "document_quality_issues": [],
      "total_documents_reviewed": 1
    }
  },
  "recommendation": {
    "decision": "dispute",
    "rationale": "As evidências sustentam fortemente a posição do comerciante",
    "next_steps": ["Enviar comprovante de entrega como evidência principal", "Incluir log de rastreamento"]
  }
}
```

#### Campos da Resposta de Recomendação

| **Campo**                                                    | **Tipo**        | **Descrição**                                                                       |
| -------------------------------------------------------------- | --------------- | -------------------------------------------------------------------------------------- |
| `status`                                                       | String          | Status do processamento da recomendação                                                |
| `analysis`                                                     | Object          | Análise da disputa e das evidências pela IA                                            |
| `analysis.primary_defense_scenario`                            | String          | Principal estratégia de defesa identificada para a disputa                             |
| `analysis.evidence_quality`                                    | String          | Avaliação geral da qualidade das evidências fornecidas                                 |
| `analysis.evidence_symbol`                                     | String          | Indicador visual da qualidade das evidências                                           |
| `analysis.key_strengths`                                       | Array\<String\> | Fatores que sustentam a posição do comerciante                                         |
| `analysis.key_weaknesses`                                      | Array\<String\> | Lacunas ou pontos fracos nas evidências atuais                                         |
| `analysis.win_probability`                                     | Object          | Probabilidade estimada de ganhar a disputa                                             |
| `analysis.win_probability.confidence_level`                    | String          | Nível de confiança da estimativa (ex.: `high`, `medium`, `low`)                       |
| `analysis.win_probability.range`                               | String          | Intervalo de probabilidade expresso em percentual                                      |
| `analysis.win_probability.percentage`                          | Integer         | Estimativa central de probabilidade em percentual                                      |
| `analysis.document_analysis`                                   | Object          | Avaliação dos documentos enviados                                                      |
| `analysis.document_analysis.critical_documents_present`        | Array\<String\> | Documentos críticos presentes para a disputa                                           |
| `analysis.document_analysis.missing_critical_documents`        | Array\<String\> | Documentos críticos ausentes                                                           |
| `analysis.document_analysis.document_quality_issues`           | Array\<String\> | Problemas de qualidade identificados nos documentos enviados                           |
| `analysis.document_analysis.total_documents_reviewed`          | Integer         | Total de documentos analisados                                                         |
| `recommendation`                                               | Object          | Recomendação final                                                                     |
| `recommendation.decision`                                      | String          | Ação recomendada (ex.: `dispute`, `accept`)                                           |
| `recommendation.rationale`                                     | String          | Justificativa da recomendação                                                          |
| `recommendation.next_steps`                                    | Array\<String\> | Lista ordenada de ações a executar                                                     |
