# Datos de API – IA Agente – Contracargo

## Privacidad de Datos y Cumplimiento

Ningún número de tarjeta (PAN), CVV u otro dato de autenticación de la tarjeta se envía al motor de recomendación por IA — solo se utilizan la red de la tarjeta (`card_brand`) y datos agregados/enmascarados de la transacción (montos, fechas e identificadores internos). Los campos de texto libre (`cardholder_claim`, `merchant_response`) pueden contener datos personales proporcionados por las partes de la disputa y se procesan únicamente con fines de recomendación de contracargo y análisis de evidencias. Los archivos de evidencia se procesan solo para OCR y clasificación de documentos; no se extrae ni almacena ningún dato de autenticación del tarjetahabiente (datos de pista, PIN, CVV). Este tratamiento se realiza conforme a la LGPD (Ley 13.709/2018), el GDPR y los principios de minimización de datos y limitación de alcance del PCI-DSS.

## Motor de Recomendación por IA

![Recomendación de IA](../images/ai-recommendation.png)

Entrada

```jsonc
{
  "organization_id": "org_12133232",
  "contract_dispute_id": "cd_1234567890",
  "cycle_id": "cy_1223232",
  "language": "es",
  "reason_code": "13.1 - Merchandise/Services Not Received",
  "card_brand": "visa", // enum: visa | master | elo | amex
  "transaction": {
    "authorized_at": "2025-01-15T14:30:00Z",
    "merchant_id": "MERCH-12345",
    "currency": "USD",
    "amount": 29999
  },
  "chargeback": {
    "received_at": "2025-02-20T09:15:00Z",
    "cycle_type": null,
    "amount": 29999
  },
  "details": {
    "cardholder_claim": "El cliente afirma que el paquete nunca fue entregado a pesar de que el seguimiento muestra confirmación de entrega",
    "merchant_response": "El comerciante refuta la reclamación"
  }
}
```

### Campos de la Solicitud de Recomendación

| **Campo**                  | **Tipo**            | **Requerido** | **Descripción**                                                          | **Ejemplo**                                          |
| --------------------------- | -------------------- | --------------- | ----------------------------------------------------------------------- | -------------------------------------------------------|
| `organization_id`           | String                | Sí               | Identificador interno de la organización en Tupi                        | `"org_12133232"`                                        |
| `contract_dispute_id`       | String                | Sí               | Identificador interno único del contrato de disputa en Tupi             | `"cd_1234567890"`                                       |
| `cycle_id`                  | String                | Sí               | Identificador interno del ciclo de disputa en Tupi                      | `"cy_1223232"`                                          |
| `language`                  | String (ISO 639-1)   | Sí               | Código de idioma utilizado para textos                                  | `"es"`                                                  |
| `reason_code`                | String                | Sí               | Código de motivo y descripción del contracargo según la red             | `"13.1 - Merchandise/Services Not Received"`            |
| `card_brand`                 | String (enum)         | Sí               | Red/marca de tarjeta involucrada en la transacción. Valores: `visa`, `master`, `elo`, `amex` | `"visa"`                          |
| `transaction`                | Object                 | No               | Detalles de la transacción original                                      | *Ver subcampos abajo*                                   |
| `transaction.authorized_at`  | String (RFC 3339)     | No               | Fecha y hora de autorización de la transacción original (UTC)           | `"2025-01-15T14:30:00Z"`                                |
| `transaction.merchant_id`    | String                 | No               | Identificador único del comerciante                                      | `"MERCH-12345"`                                         |
| `transaction.currency`       | String                 | No               | Código de moneda de la transacción                                       | `"USD"`                                                 |
| `transaction.amount`         | Decimal                | Sí               | Monto de la transacción en la unidad monetaria más pequeña               | `29999` (=$299.99)                                      |
| `chargeback`                  | Object                 | Sí               | Detalles específicos de la disputa                                       | *Ver subcampos abajo*                                   |
| `chargeback.received_at`      | String (RFC 3339)      | Sí               | Fecha y hora en que se recibió el contracargo (UTC)                     | `"2025-02-20T09:15:00Z"`                                |
| `chargeback.cycle_type`       | String                  | No               | Tipo de ciclo de disputa, cuando aplique                                  | `null`                                                  |
| `chargeback.amount`           | Decimal                 | Sí               | Monto del contracargo en la unidad monetaria más pequeña                 | `29999`                                                 |
| `details`                      | Object                  | No               | Información adicional de la disputa                                      | *Ver subcampos abajo*                                   |
| `details.cardholder_claim`     | String                  | No               | Descripción de la reclamación realizada por el tarjetahabiente           | `"El cliente afirma que el paquete nunca fue entregado..."`|
| `details.merchant_response`    | String                  | No               | Descripción de la respuesta proporcionada por el comerciante             | `"El comerciante refuta la reclamación"`                |

## Envío de Evidencias

Los archivos de evidencia (p. ej., comprobante de entrega, facturas, registros de comunicación) se envían en una solicitud separada en formato `multipart/form-data`, vinculados a la misma disputa mediante los identificadores indicados abajo. Cada archivo se procesa de forma independiente para OCR y clasificación de documentos, y el resultado se asocia a la disputa.

### Campos de la Solicitud de Envío de Evidencia

| **Campo**             | **Tipo**  | **Requerido** | **Descripción**                                                    | **Ejemplo**            |
| ----------------------- | --------- | --------------- | ------------------------------------------------------------------- | -------------------------|
| `file`                   | Binario   | Sí               | Contenido del archivo de evidencia                                  | *archivo binario*         |
| `organization_id`        | String    | Sí               | Identificador interno de la organización en Tupi                    | `"org_12133232"`          |
| `contract_dispute_id`    | String    | Sí               | Identificador interno único del contrato de disputa en Tupi         | `"cd_1234567890"`         |
| `cycle_id`               | String    | Sí               | Identificador interno del ciclo de disputa en Tupi                  | `"cy_1223232"`            |
| `step_id`                | String    | Sí               | Identificador del paso de la disputa al que pertenece la evidencia  | `"step_123456"`           |
| `step_type`              | String    | Sí               | Tipo del paso de la disputa                                          | `"chargeback"`            |
| `reason_code`             | String    | No               | Código de motivo del contracargo, cuando aplique                    | `"10.1"`                  |
| `filename`                | String    | Sí               | Nombre original del archivo                                          | `"evidence.pdf"`          |
