# Datos de API – IA Agente – Contracargo

## Privacidad de Datos y Cumplimiento

Ningún número de tarjeta (PAN), CVV u otro dato de autenticación de la tarjeta se envía al motor de recomendación por IA — solo se utilizan la red de la tarjeta (`card_brand`) y datos agregados/enmascarados de la transacción (montos, fechas e identificadores internos). Los campos de texto libre (`cardholder_claim`, `merchant_response`) pueden contener datos personales proporcionados por las partes de la disputa y se procesan únicamente con fines de recomendación de contracargo y análisis de evidencias. Los archivos de evidencia se procesan solo para OCR y clasificación de documentos; no se extrae ni almacena ningún dato de autenticación del tarjetahabiente (datos de pista, PIN, CVV). Este tratamiento se realiza conforme a la LGPD (Ley 13.709/2018), el GDPR y los principios de minimización de datos y limitación de alcance del PCI-DSS.

## Envío de Evidencias

Los archivos de evidencia (p. ej., comprobante de entrega, facturas, registros de comunicación) se envían en una solicitud separada en formato `multipart/form-data`, vinculados a la misma disputa mediante los identificadores indicados abajo. Cada archivo se procesa de forma independiente para OCR y clasificación de documentos, y el resultado se asocia a la disputa.

### Campos de la Solicitud de Envío de Evidencia

| **Campo**             | **Tipo**  | **Requerido** | **Descripción**                                                    | **Ejemplo**            |
| ----------------------- | --------- | --------------- | ------------------------------------------------------------------- | -------------------------|
| `file`                   | Binario   | Sí               | Contenido del archivo de evidencia                                  | *archivo binario*         |
| `organization_id`        | String    | Sí               | Identificador interno de la organización en Tupi                    | `"org_12133232"`          |
| `contract_dispute_id`    | String    | Sí               | Identificador interno único del contrato de disputa en Tupi         | `"cd_1234567890"`         |
| `cycle_id`               | String    | Sí               | Identificador interno del ciclo de disputa en Tupi                  | `"cy_1223232"`            |
| `step_id`                | String    | Sí               | Identificador del paso de la disputa al que pertenece la evidencia  | `"step_123456"`           |
| `step_type`              | String    | Sí               | Tipo del paso de la disputa                                          | `"chargeback"`            |
| `reason_code`             | String    | No               | Código de motivo del contracargo, cuando aplique                    | `"10.1"`                  |
| `filename`                | String    | Sí               | Nombre original del archivo                                          | `"evidence.pdf"`          |

### Resultado del Análisis por IA

Luego de que el pipeline de IA/OCR procesa el archivo, los siguientes datos son extraídos y persistidos. Este registro se utiliza en el flujo de recomendación y documenta los datos derivados de las evidencias enviadas por el partner.

```jsonc
{
  "status": "success",
  "request_id": "req_abc123",
  "document": {
    "filename": "evidence.pdf",
    "category": "proof_of_delivery"
  },
  "extracted_data": {
    "raw_text": "Entregado el 15/01/2025 a las 14:30, firmado por J. Silva",
    "analysis": {
      "document_intent": "Confirma la entrega de los bienes en el domicilio del tarjetahabiente",
      "missing_info": "No se incluye imagen de la firma",
      "confidence_summary": "Alta confianza — fecha de entrega y nombre del destinatario presentes"
    }
  },
  "metadata": {
    "processing_time_ms": 1240,
    "llm_model": "...",   // proveedor no divulgado
    "ocr_method": "...",  // proveedor no divulgado
    "token_usage": {
      "prompt_tokens": 512,
      "response_tokens": 128,
      "total_tokens": 640
    }
  }
}
```

| **Campo**                                     | **Tipo**  | **Descripción**                                                                       |
| ----------------------------------------------- | --------- | ---------------------------------------------------------------------------------------- |
| `status`                                        | String    | Estado del procesamiento                                                                  |
| `request_id`                                    | String    | Identificador único de la solicitud de análisis                                           |
| `document`                                      | Object    | Información sobre el documento analizado                                                  |
| `document.filename`                             | String    | Nombre original del archivo                                                               |
| `document.category`                             | String    | Categoría del documento identificada por la IA (p. ej., `proof_of_delivery`, `invoice`)  |
| `extracted_data`                                | Object    | Datos extraídos del documento                                                             |
| `extracted_data.raw_text`                       | String    | Texto completo extraído del documento vía OCR                                             |
| `extracted_data.analysis`                       | Object    | Interpretación del contenido del documento por la IA                                     |
| `extracted_data.analysis.document_intent`       | String    | Resumen de lo que el documento demuestra en el contexto de la disputa                    |
| `extracted_data.analysis.missing_info`          | String    | Información esperada pero ausente en el documento                                         |
| `extracted_data.analysis.confidence_summary`    | String    | Evaluación legible de la confianza en los datos extraídos                                 |
| `metadata`                                      | Object    | Metadatos del procesamiento                                                               |
| `metadata.processing_time_ms`                   | Integer   | Tiempo de procesamiento del documento, en milisegundos                                    |
| `metadata.llm_model`                            | String    | Modelo de IA utilizado (proveedor no divulgado)                                           |
| `metadata.ocr_method`                           | String    | Método de OCR utilizado (proveedor no divulgado)                                          |
| `metadata.token_usage`                          | Object    | Consumo de tokens del análisis por IA                                                     |
| `metadata.token_usage.prompt_tokens`            | Integer   | Tokens utilizados en el prompt                                                            |
| `metadata.token_usage.response_tokens`          | Integer   | Tokens utilizados en la respuesta                                                         |
| `metadata.token_usage.total_tokens`             | Integer   | Total de tokens consumidos                                                                |

## Motor de Recomendación por IA

![Recomendación de IA](../images/ai-recommendation.png)

### Solicitud

Entrada

```jsonc
{
  "organization_id": "org_12133232",
  "contract_dispute_id": "cd_1234567890",
  "cycle_id": "cy_1223232",
  "language": "es",
  "reason_code": "13.1 - Merchandise/Services Not Received",
  "card_brand": "visa", 
  "transaction": {
    "authorized_at": "2025-01-15T14:30:00Z",
    "merchant_id": "MERCH-12345",
    "currency": "USD",
    "amount": 29999
  },
  "chargeback": {
    "received_at": "2025-02-20T09:15:00Z",
    "cycle_type": null,
    "amount": 29999
  },
  "details": {
    "cardholder_claim": "El cliente afirma que el paquete nunca fue entregado a pesar de que el seguimiento muestra confirmación de entrega",
    "merchant_response": "El comerciante refuta la reclamación"
  }
}
```

#### Campos de la Solicitud de Recomendación

| **Campo**                  | **Tipo**            | **Requerido** | **Descripción**                                                          | **Ejemplo**                                          |
| --------------------------- | -------------------- | --------------- | ----------------------------------------------------------------------- | -------------------------------------------------------|
| `organization_id`           | String                | Sí               | Identificador interno de la organización en Tupi                        | `"org_12133232"`                                        |
| `contract_dispute_id`       | String                | Sí               | Identificador interno único del contrato de disputa en Tupi             | `"cd_1234567890"`                                       |
| `cycle_id`                  | String                | Sí               | Identificador interno del ciclo de disputa en Tupi                      | `"cy_1223232"`                                          |
| `language`                  | String (ISO 639-1)   | Sí               | Código de idioma utilizado para textos                                  | `"es"`                                                  |
| `reason_code`                | String                | Sí               | Código de motivo y descripción del contracargo según la red             | `"13.1 - Merchandise/Services Not Received"`            |
| `card_brand`                 | String (enum)         | Sí               | Red/marca de tarjeta involucrada en la transacción. Valores: `visa`, `master`, `elo`, `amex` | `"visa"`                          |
| `transaction`                | Object                 | No               | Detalles de la transacción original                                      | *Ver subcampos abajo*                                   |
| `transaction.authorized_at`  | String (RFC 3339)     | No               | Fecha y hora de autorización de la transacción original (UTC)           | `"2025-01-15T14:30:00Z"`                                |
| `transaction.merchant_id`    | String                 | No               | Identificador único del comerciante                                      | `"MERCH-12345"`                                         |
| `transaction.currency`       | String                 | No               | Código de moneda de la transacción                                       | `"USD"`                                                 |
| `transaction.amount`         | Decimal                | Sí               | Monto de la transacción en la unidad monetaria más pequeña               | `29999` (=$299.99)                                      |
| `chargeback`                  | Object                 | Sí               | Detalles específicos de la disputa                                       | *Ver subcampos abajo*                                   |
| `chargeback.received_at`      | String (RFC 3339)      | Sí               | Fecha y hora en que se recibió el contracargo (UTC)                     | `"2025-02-20T09:15:00Z"`                                |
| `chargeback.cycle_type`       | String                  | No               | Tipo de ciclo de disputa, cuando aplique                                  | `null`                                                  |
| `chargeback.amount`           | Decimal                 | Sí               | Monto del contracargo en la unidad monetaria más pequeña                 | `29999`                                                 |
| `details`                      | Object                  | No               | Información adicional de la disputa                                      | *Ver subcampos abajo*                                   |
| `details.cardholder_claim`     | String                  | No               | Descripción de la reclamación realizada por el tarjetahabiente           | `"El cliente afirma que el paquete nunca fue entregado..."`|
| `details.merchant_response`    | String                  | No               | Descripción de la respuesta proporcionada por el comerciante             | `"El comerciante refuta la reclamación"`                |

### Respuesta

```jsonc
{
  "status": "processed",
  "analysis": {
    "primary_defense_scenario": "Comprobante de entrega disponible",
    "evidence_quality": "strong",
    "evidence_symbol": "✅",
    "key_strengths": ["Confirmación de entrega firmada", "El registro de seguimiento coincide con los registros del comerciante"],
    "key_weaknesses": ["Sin registro de comunicación con el cliente"],
    "win_probability": {
      "confidence_level": "high",
      "range": "75-90%",
      "percentage": 82
    },
    "document_analysis": {
      "critical_documents_present": ["delivery_confirmation.pdf"],
      "missing_critical_documents": [],
      "document_quality_issues": [],
      "total_documents_reviewed": 1
    }
  },
  "recommendation": {
    "decision": "dispute",
    "rationale": "La evidencia respalda sólidamente la posición del comerciante",
    "next_steps": ["Enviar comprobante de entrega como evidencia principal", "Incluir registro de seguimiento"]
  }
}
```

#### Campos de la Respuesta de Recomendación

| **Campo**                                                    | **Tipo**        | **Descripción**                                                                      |
| -------------------------------------------------------------- | --------------- | --------------------------------------------------------------------------------------- |
| `status`                                                       | String          | Estado del procesamiento de la recomendación                                             |
| `analysis`                                                     | Object          | Análisis de la disputa y las evidencias por la IA                                        |
| `analysis.primary_defense_scenario`                            | String          | Principal estrategia de defensa identificada para la disputa                             |
| `analysis.evidence_quality`                                    | String          | Evaluación general de la calidad de las evidencias proporcionadas                        |
| `analysis.evidence_symbol`                                     | String          | Indicador visual de la calidad de las evidencias                                         |
| `analysis.key_strengths`                                       | Array\<String\> | Factores que respaldan la posición del comerciante                                       |
| `analysis.key_weaknesses`                                      | Array\<String\> | Brechas o puntos débiles en las evidencias actuales                                      |
| `analysis.win_probability`                                     | Object          | Probabilidad estimada de ganar la disputa                                                |
| `analysis.win_probability.confidence_level`                    | String          | Nivel de confianza de la estimativa (p. ej., `high`, `medium`, `low`)                  |
| `analysis.win_probability.range`                               | String          | Intervalo de probabilidad expresado como porcentaje                                      |
| `analysis.win_probability.percentage`                          | Integer         | Estimativa central de probabilidad en porcentaje                                         |
| `analysis.document_analysis`                                   | Object          | Evaluación de los documentos enviados                                                    |
| `analysis.document_analysis.critical_documents_present`        | Array\<String\> | Documentos críticos presentes para la disputa                                            |
| `analysis.document_analysis.missing_critical_documents`        | Array\<String\> | Documentos críticos ausentes                                                             |
| `analysis.document_analysis.document_quality_issues`           | Array\<String\> | Problemas de calidad identificados en los documentos enviados                            |
| `analysis.document_analysis.total_documents_reviewed`          | Integer         | Total de documentos revisados                                                            |
| `recommendation`                                               | Object          | Recomendación final                                                                      |
| `recommendation.decision`                                      | String          | Acción recomendada (p. ej., `dispute`, `accept`)                                        |
| `recommendation.rationale`                                     | String          | Justificación de la recomendación                                                        |
| `recommendation.next_steps`                                    | Array\<String\> | Lista ordenada de acciones a ejecutar                                                    |
